Metrics — Formulas

How each KPI is computed. Counts are per player or team as shown in the dashboards.
  • Attack Efficiency = (AK − AE) / (AK + AE + AB + A-)
  • Good Dig % = (D3 + D2) / (D3 + D2 + D1 + D0)
  • Good Receive % = (R3 + R2) / (R3 + R2 + R1 + R0)
  • Receive Average (0–3) = (3·R3 + 2·R2 + 1·R1 + 0·R0) / (R3 + R2 + R1 + R0)
  • Block Rate = BK / (BK + BT + BE)
  • Side Out % = Side-out successes / Side-out opportunities
    An opportunity is any rally following the opponent's serve; a success is your side winning that rally, determined by the last point-ending action logged (ace, kill, block, or an error) — extended rallies with no such action logged aren't counted either way.
  • +/− = (AK + SA + BK) − (AE + AB + SE + BE)
